# Composite project licensing

There is no single blanket open-source license for every file in this
repository.

1. **X-Ray/GSC-derived source.** The source derived from the X-Ray engine is
   governed by [`License.txt`](License.txt), including its non-commercial
   restriction. That license is retained; it is not replaced by MIT, Apache-2.0,
   GPL, or any other permissive open-source license.
2. **Third-party components.** Code under `src/3rd party/`, `Externals/`, and
   `sdk/include/` may have separate copyright and license terms. The notices in
   those components control their use. A repository-level license cannot
   override them.
3. **Project additions.** New files and modifications in this port are
   published for non-commercial research and compatibility work subject to the
   same limitations stated in `License.txt`, unless a file or its upstream
   notice says otherwise. No trademark license or permission to redistribute
   S.T.A.L.K.E.R. Anomaly, GAMMA, or any game/mod assets is granted.

This arrangement is intentionally source-available and non-commercial, not
OSI-approved open source. It is the most conservative choice for a derivative
engine project whose tree contains GSC-derived code and separately licensed
third-party components.

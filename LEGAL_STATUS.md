# Legal and permission status

This is an engineering assessment, not legal advice.

## Anomaly

The Anomaly project page describes Anomaly as a standalone, fan-created
modification and identifies it as a custom fork of the X-Ray engine. It also
states that Anomaly is not an official GSC product. The project page does not
provide a separate blanket license that would let this repository relicense
Anomaly code, assets, or all of its bundled content.

Accordingly, this repository does not claim to be an Anomaly fork or to own
Anomaly's content. It publishes only the engine-port work and keeps Anomaly
runtime data out of the tree.

## GAMMA

GAMMA's public repository uses AGPL-3.0 for the material covered by that
repository, but its README also explains that GAMMA is assembled from many
modders' work and that numbered add-ons require contacting their original
authors before reposting or modifying them. AGPL-3.0 therefore cannot be
treated as a license for every GAMMA add-on, shader, model, texture, sound, or
script.

This repository does not redistribute GAMMA's modpack, add-ons, assets, or
runtime profile. References to GAMMA mean compatibility testing only and are
not a license grant from the GAMMA team or its contributors.

## Practical conclusion

The source-only publication is substantially safer than publishing the local
runtime, binaries, game data, or a repacked GAMMA installation. However, the
current project is a native Apple-platform/Metal port, and the relevant
upstream terms and rights-holder policies must still be checked before public
binary distribution or a release intended for end users.

No statement in this repository should be read as an endorsement by GSC,
Anomaly developers, GAMMA developers, or any third-party mod author. When in
doubt about a particular file, remove it from the public tree and ask its
copyright holder for written permission.

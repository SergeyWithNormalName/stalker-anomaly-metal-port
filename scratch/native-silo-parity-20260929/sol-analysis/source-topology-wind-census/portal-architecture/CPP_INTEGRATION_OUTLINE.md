# C++ portal-visibility integration outline (review before implementation)

This is a design sketch only. The live frame replay is still an offline, no-suppression result; no C++ graph integration is proposed in this task.

## Reuse the existing level parser and source math

1. **Load one winning input generation.** At the Metal level lifecycle, copy the active `IReader` bytes into owned storage and parse those same bytes. Extend the existing `ParseR4LevelGeometry` path to accept the active `level` byte vector instead of reopening `level` from `levelDirectory`; preferably obtain `level.geom` through the engine FS reader too, so OGF IDs, portal topology, and draw geometry come from one resolved level generation. Keep `LoadR4LevelGeometry` as a file-backed wrapper for current callers. Do not retain an `IReader*` or `CDB` pointer across a frame or unload.
2. **Extend the parser result, not a second OGF parser.** `R4LevelGeometry` already indexes `fsL_VISUALS`, OGF headers, linked children and static descendants (`R4LevelGeometry.cpp:558-639, 758-825`). Retain each OGF header AABB/sphere with `R4VisualNode`; parse `fsL_SECTORS` roots/portal-ID lists and `fsL_PORTALS` endpoints/ordered vertices during the same validated chunk walk. Produce value-owned `R4PortalTopology` records and a multi-owner visual-to-sector map. Preserve overlapping root ownership; invalid links, cycles, bounds, or portal IDs make the topology unusable for exclusion.
3. **Build portal geometry with engine types.** Store sector/portal IDs and vertex indices as values. On level-generation creation, materialize source `CPortal` values and call `CPortal::Setup` for the source `BB`, `S`, and plane calculations. Keep sector ownership as indices; leave the `CPortal` face/back pointers null and do not attach source `CSector` or visual objects.
4. **Factor a pure source walker around `CFrustum`.** Add a narrow CPU API beside the source sector code, taking immutable topology plus a frame input value and returning per-sector `std::vector<CFrustum>` and a validity reason. Reuse `CFrustum::CreateFromMatrix`, `testSphere_dirty`, `ClipPoly`, `CreateFromPortal` (its body matches the source `CreateFrustumFromPortal` helper), and `testSAABB`; use `CPortal::Setup` values for portal sphere/plane. Mirror the current `CSector::traverse` ordering, current-eye (`DM.i_vBase`) neighbor test, saved-eye/`ViewportNear` dual-render test, exact SSA early-continue order, per-sector visited portal sets and multiple frusta. Do not copy the Python math into the runtime C++ path. Keep HOM disabled for the conservative superset; if any future HOM or fade path is added, make its inputs explicit.
5. **Use CDB for start-sector parity.** Build the portal triangle model from copied portal vertices with the source `CDB::Collector`/`CDB::MODEL` ownership pattern (or factor that source builder into a helper). At each primary view, query the owned portal model first, apply source portal-facing and root-AABB containment, then query the live `CObjectSpace` static model for the nearest sector-tagged CFORM hit. The current actual frame qualifies sector 25 because both CFORM rays report sector 25 and the copied portal mesh has no vertical hit at this eye. If either query is ambiguous, generation changes, or no root bounds exist, mark the visibility frame invalid and admit all.
6. **Capture the actual source view once.** At the primary `CRender::Calculate` boundary, pass an immutable frame record with `Device.vCameraPosition` (`DM.i_vBase`), `Device.vCameraPosition_saved`, `Device.mFullTransform`, `Device.ViewportNear`, `GMBase.i_options`, `r_ssaDISCARD`, `r_ssaLOD_A/B`, `rsDrawPortals`, engine frame, and active level generation. Reject nonfinite values and any view/pass/frame mismatch. The live observer now verifies saved eye equals current eye for frame 700, but the API must keep the fields separate.

## First consumer and failure behavior

Start with observe-only mapping of main static/Flora G-buffer candidates. Join each draw ID through all owning sector roots and consider it outside only if its conservative world/motion envelope is outside every retained frustum for every owner. Use the exact source indexed position bounds and a current, qualified wind envelope; unknown bender or missing owner/bounds means retain. Keep the existing Metal view-frustum test as an independent earlier check. Do not filter dynamic-world candidates, local-light capture, prewarm, HUD, scopes or any shadow route in this first consumer.

The graph cache belongs to the renderer scene generation and is cleared by the existing `MetalRenderDeviceRender::UnloadLevelScene`/`LoadLevelScene` lifecycle. Store indices and owned vectors only. A parse, CDB, generation, camera, wind, or math failure returns “no portal exclusions”; it never fails gameplay preparation and never removes a draw.

## Required gates before any suppression

- Source parser selftests for malformed chunks/references, duplicate/multi-root ownership and cycles; C++ topology/walker tests for source portal plane orientation, SSA hard discard before LOD_B, near-camera selection using saved eye, two paths to one sector, visited-per-sector cycles, multiple frusta, and fail-open malformed input.
- Live observer must join the same winning `level`/`level.geom` generation, same primary frame matrices, live near/saved-eye/threshold values, start sector 25, and expected sectors/frusta before any candidate IDs are compared.
- Per-ID observe-only proof must match all 5,316 frame-700 source Flora IDs and preserve the existing `4,427/889` raw OGF bounds partition. Then apply the current indexed-mesh and wind envelope and require the prior 4,086 bound exclusions, with unknown motion failing open.
- Any eventual skip remains main-G-buffer-only. A separate light-space proof is required before changing shadow casters or shadow prewarm; portal visibility cannot stand in for shadow visibility.

The present active-data replay matches the old `4,427/889` raw partition and reports zero portal vertical hits. It is a parser/walker qualification for this frame, not source hierarchy admission, temporal wind qualification, image parity, performance acceptance, or a shipping cull.

# Runtime portal census candidate (scratch only)

`runtime-observer.patch` stages a default-off, frame-700-only observer. It leaves all draw/admission and shadow code unchanged and writes `suppressed=0`. The candidate has not been built or run; root owns that validation.

At Metal `level_Load`, a copy of the active `IReader` is saved without advancing its cursor. Generation remains zero unless the copy flushes/closes with the exact byte count, and resets before load and unload. At scene Prepare, the candidate requires a nonzero copied-reader generation, hashes the copy, compares its bytes against the host `level` file used for the scene, and parses those active bytes with the same retained `level.geom` bytes. It builds the owned portal-model/context cache once; any missing/mismatched input or parser/cache error remains a diagnostic unavailable state and does not fail gameplay preparation. The cache retains parser values/CDB portal model only, no engine reader, `CSector`, `CPortal`, `CDB::RESULT`, or static CFORM pointer.

At frame 700, after the existing scene-ready check and `GMBase.traverse`, `CRender::Calculate` copies current/saved eyes, view/projection/full matrices, viewport near, SSA values and portal flag, then synchronously passes `CDB::MODEL*` returned by `ObjectSpace.GetStaticModel()`. The scene observer consumes it during source `detectLastSector` emulation and never stores it. HOM is forced off (context options 6). A selected primary scene view must match Calculate's engine frame and exact view/projection/eye bits. The Flora observer writes its existing same-frame ID CSV; `OnFrameSubmitted` requires the terminal `encode_complete,5316`, unique IDs, frame/extent and bitwise view/projection/eye/SSA agreement, and valid visual-index joins before writing `complete=true`.

The receipt includes active-reader SHA-256, generation/frame/start sector, reached frusta with plane values, per-ID raw visibility and owner-frustum-test counts, plus initialization and frame observer CPU time. Missing IDs, stale generation, failed view match, unqualified cache, or discarded submission cannot produce a complete receipt. No build, game, shader cook, or production edit was performed.

The active-reader copy authenticates `level`; `level.geom` identity still depends on the run wrapper's exact runtime hash pin. The candidate's host/active raw `level` equality is intentionally fail-closed and may reject valid VFS cases where host bytes differ even if the game loaded a coherent modded level. The runtime observer is a source-math diagnostic, not proof of GPU visibility equivalence or an admission policy.

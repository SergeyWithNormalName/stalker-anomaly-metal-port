# V9 active-occlusion/catalog observer preparation (scratch only)

This directory stages one future observe-only V9 run. Candidate V9 has been built and pinned, but has not been launched. The runner points only to `candidate-v9/Anomaly.app`; it still refuses launch until the root approval token is supplied.

The planned run uses the V2 canonical Cordon runtime/save and fixed observer camera, enables compute skin + dynamic shadow index + instanced Flora, explicitly unsets `XRAY_METAL_STATIC_CONSTANT_GROUPS`, and enables only the existing active-occlusion CPU observation plus whole-light GPU visibility observer for engine frames300–311. Lua ends the observation window after frame311, drains about1.5 seconds (normally through frame342), then quits. The wrapper owns the direct executable PID with a 180-second limit; no OS screenshot, native color probe, FPS instrumentation, E01/E07/E08 detail timers, or CPU sampling is enabled.

`observer_window_v9.lua` is byte-for-byte copied from the qualified fixed-window V7 Lua. The parser requires exactly one enabled catalog PREP record with the frozen reason, nonnegative counts, a minimum storage-byte lower bound, catalog limits, and candidate-to-catalog visual reconciliation. Every qualifying GRID record must include the frozen selector/receipt counters, satisfy catalog-relative draw/triangle arithmetic and hard caps, identify `raster_convention=synthetic_only` and `suppression=disabled`, and agree with its CPU face rows. A catalog, selector, CPU identity, or GPU receipt mismatch remains inconclusive; parser status 3 is reserved for a validated CPU-behind face paired with a valid nonzero submitted GPU receipt. The schema file records the frozen field names/types and source hashes.

The measurement scope is observation coverage/correlation and bounded work counts. Zero GPU receiver samples do not imply a cull, unselected work is unknown, and no FPS or visual acceptance claim is made. Missing/malformed observation data returns parser status 2; status 1 is execution-integrity failure.
